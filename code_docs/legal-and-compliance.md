法律协议
-------------------------------------------------------------------------------------------------------

### [​](https://code.claude.com/docs/zh-CN/legal-and-compliance#%E8%AE%B8%E5%8F%AF%E8%AF%81)

许可证

您对 Claude Code 的使用受以下条款约束：
*   [商业条款](https://www.anthropic.com/legal/commercial-terms) - 适用于 Team、Enterprise 和 Claude API 用户
*   [消费者条款](https://www.anthropic.com/legal/consumer-terms) - 适用于 Free、Pro 和 Max 用户

### [​](https://code.claude.com/docs/zh-CN/legal-and-compliance#%E5%95%86%E4%B8%9A%E5%8D%8F%E8%AE%AE)

商业协议

无论您是直接使用 Claude API（1P）还是通过 AWS Bedrock 或 Google Vertex（3P）访问它，您现有的商业协议将适用于 Claude Code 使用，除非我们相互另有约定。
[​](https://code.claude.com/docs/zh-CN/legal-and-compliance#%E5%90%88%E8%A7%84)

合规
-----------------------------------------------------------------------------------

### [​](https://code.claude.com/docs/zh-CN/legal-and-compliance#%E5%8C%BB%E7%96%97%E4%BF%9D%E5%81%A5%E5%90%88%E8%A7%84%EF%BC%88baa%EF%BC%89)

医疗保健合规（BAA）

如果客户与我们签订了业务关联协议（BAA），并想使用 Claude Code，如果客户已执行 BAA 并激活了零数据保留（ZDR），BAA 将自动扩展以覆盖 Claude Code。BAA 将适用于通过 Claude Code 流动的该客户的 API 流量。
[​](https://code.claude.com/docs/zh-CN/legal-and-compliance#%E5%AE%89%E5%85%A8%E5%92%8C%E4%BF%A1%E4%BB%BB)
