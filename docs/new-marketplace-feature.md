# 新版插件市场功能说明

## 功能概述

新版插件市场页面实现了你要求的所有功能：

1. **命令行接口** - 支持 `/plugin marketplace add udecode/dotai` 格式的命令
2. **市场列表** - 显示已添加的所有市场，包含插件数量统计
3. **分层浏览** - 市场 → 插件列表 → 插件详情 → 能力详情
4. **能力分类** - 自动分类展示各种类型的能力
5. **下载功能** - 支持将单个能力下载到本地能力库

## 页面结构

### 1. 市场列表页面
- **顶部命令输入框**
  - 支持完整命令输入：`/plugin marketplace add udecode/dotai`
  - 自动解析命令格式
  - Enter 键快速执行

- **市场卡片列表**
  - 显示市场名称
  - 插件数量统计
  - 市场描述信息
  - 来源仓库地址
  - 最后更新时间

### 2. 插件列表页面
- **返回按钮** - 返回市场列表
- **插件卡片**
  - 插件名称和版本
  - 插件描述
  - 能力类型统计（带图标）
  - 查看详情按钮

### 3. 插件详情页面
- **返回按钮** - 返回插件列表
- **插件基本信息**
  - 名称、版本、描述
- **能力分类展示**
  - 按类型分组显示
  - 每个能力的名称和路径
  - 下载按钮

## 能力分类

根据 Claude 插件的规范，支持以下能力类型：

| 类型 | 说明 | 图标 | 颜色 |
|------|------|------|------|
| **Agents** | AI 助手/代理 | 🤖 | 蓝色 |
| **Skills** | 特殊技能/能力 | ⚡ | 紫色 |
| **Commands** | Slash 命令 | 💻 | 绿色 |
| **Hooks** | 事件钩子 | 🪝 | 橙色 |
| **MCP 服务器** | Model Context Protocol 服务器 | 🔌 | 红色 |
| **配置** | 配置文件 | ⚙️ | 灰色 |
| **提示词** | Prompt 模板 | 💬 | 靛蓝色 |

## 使用流程

1. **添加市场**
   ```
   在输入框输入：/plugin marketplace add udecode/dotai
   点击"添加"按钮
   ```

2. **浏览市场**
   ```
   点击市场卡片进入插件列表
   查看该市场的所有插件
   ```

3. **查看插件详情**
   ```
   点击插件的"查看详情"按钮
   浏览插件包含的所有能力
   按类型分组显示
   ```

4. **下载能力**
   ```
   点击能力旁的"下载到能力库"按钮
   将单个能力保存到本地库
   (功能开发中...)
   ```

## 技术实现

### 1. Claude CLI 集成
- 通过 `child_process` 执行 Claude CLI 命令
- 封装在 `claudeCli.ts` 服务中
- 提供完整的错误处理和日志

### 2. 数据流
```
Claude CLI → 配置文件 → Electron IPC → React 组件
```

### 3. 状态管理
- 使用 Zustand 管理全局状态
- 三层导航状态：市场列表 → 插件列表 → 插件详情
