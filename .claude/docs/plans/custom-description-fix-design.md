# 自定义描述显示问题解决方案

## 问题陈述

用户反馈：
1. 插件面板的插件卡片描述没有显示data.json中预设的自定义中文描述
2. 点击插件卡片进入插件详情页面，描述也需要显示自定义描述
3. 需要检查data.json是否包含所有插件和能力的自定义中文描述

## 初步分析

### 当前问题
1. 插件卡片（PluginCard组件）只显示原始描述 `plugin.metadata?.description`，没有加载自定义描述
2. data.json中的customDescriptions只包含了部分插件的自定义描述，还有很多插件和能力没有中文描述
3. 插件详情页面虽然已经实现了自定义描述功能，但可能存在加载问题

### 自定义描述系统理解
- **目的**：为插件和能力提供个性化中文描述，提升用户体验
- **存储**：data.json的customDescriptions字段
- **结构**：
  - plugins: 插件ID -> 自定义描述
  - capabilities: 能力ID -> 自定义描述
- **显示优先级**：有自定义描述时应默认显示自定义描述

## 要求

1. **完整性**：为所有已安装的插件和能力添加中文自定义描述
2. **显示正确**：
   - 插件卡片优先显示自定义描述
   - 插件详情页面优先显示自定义描述
   - 能力库页面优先显示自定义描述
3. **用户体验**：平滑切换原始描述和自定义描述
