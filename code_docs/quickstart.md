快速开始

快速开始
====

复制页面

欢迎使用 Claude Code！

复制页面

本快速开始指南将在几分钟内让您使用 AI 驱动的编码辅助。完成后，您将了解如何使用 Claude Code 完成常见的开发任务。
[​](https://code.claude.com/docs/zh-CN/quickstart#%E5%BC%80%E5%A7%8B%E5%89%8D)

开始前
-----------------------------------------------------------------------------------

确保您有：
*   打开的终端或命令提示符
*   一个要处理的代码项目
*   一个 [Claude.ai](https://claude.ai/)（推荐）或 [Claude Console](https://console.anthropic.com/) 账户

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-1%EF%BC%9A%E5%AE%89%E8%A3%85-claude-code)

步骤 1：安装 Claude Code
-----------------------------------------------------------------------------------------------------------------------------------

To install Claude Code, use one of the following methods:

*   Native Install (Recommended) 
*   NPM 

**Homebrew (macOS, Linux):**

复制

询问AI

```
brew install --cask claude-code
```

**macOS, Linux, WSL:**

复制

询问AI

```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

复制

询问AI

```
irm https://claude.ai/install.ps1 | iex
```

**Windows CMD:**

复制

询问AI

```
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-2%EF%BC%9A%E7%99%BB%E5%BD%95%E6%82%A8%E7%9A%84%E8%B4%A6%E6%88%B7)

步骤 2：登录您的账户
---------------------------------------------------------------------------------------------------------------------------------------------------

Claude Code 需要账户才能使用。当您使用 `claude` 命令启动交互式会话时，您需要登录：

复制

询问AI

```
claude
# 首次使用时会提示您登录
```

复制

询问AI

```
/login
# 按照提示使用您的账户登录
```

您可以使用以下任一账户类型登录：
*   [Claude.ai](https://claude.ai/)（订阅计划 - 推荐）
*   [Claude Console](https://console.anthropic.com/)（带预付额度的 API 访问）

登录后，您的凭证将被存储，您无需再次登录。

当您首次使用 Claude Console 账户对 Claude Code 进行身份验证时，会自动为您创建一个名为”Claude Code”的工作区。此工作区为您的组织中所有 Claude Code 使用情况提供集中的成本跟踪和管理。

您可以在同一电子邮件地址下拥有两种账户类型。如果您需要再次登录或切换账户，请在 Claude Code 中使用 `/login` 命令。

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-3%EF%BC%9A%E5%90%AF%E5%8A%A8%E6%82%A8%E7%9A%84%E7%AC%AC%E4%B8%80%E4%B8%AA%E4%BC%9A%E8%AF%9D)

步骤 3：启动您的第一个会话
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

在任何项目目录中打开您的终端并启动 Claude Code：

复制

询问AI

```
cd /path/to/your/project
claude
```

您将看到 Claude Code 欢迎屏幕，其中包含您的会话信息、最近的对话和最新更新。输入 `/help` 查看可用命令，或输入 `/resume` 继续之前的对话。

登录后（步骤 2），您的凭证将存储在您的系统上。在 [凭证管理](https://code.claude.com/docs/zh-CN/iam#credential-management) 中了解更多信息。

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-4%EF%BC%9A%E6%8F%90%E5%87%BA%E6%82%A8%E7%9A%84%E7%AC%AC%E4%B8%80%E4%B8%AA%E9%97%AE%E9%A2%98)

步骤 4：提出您的第一个问题
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

让我们从了解您的代码库开始。尝试以下命令之一：

复制

询问AI

```
> what does this project do?
```

Claude 将分析您的文件并提供摘要。您也可以提出更具体的问题：

复制

询问AI

```
> what technologies does this project use?
```

复制

询问AI

```
> where is the main entry point?
```

复制

询问AI

```
> explain the folder structure
```

您也可以询问 Claude 其自身的功能：

复制

询问AI

```
> what can Claude Code do?
```

复制

询问AI

```
> how do I use slash commands in Claude Code?
```

复制

询问AI

```
> can Claude Code work with Docker?
```

Claude Code 根据需要读取您的文件 - 您无需手动添加上下文。Claude 还可以访问其自己的文档，并可以回答有关其功能和特性的问题。

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-5%EF%BC%9A%E8%BF%9B%E8%A1%8C%E6%82%A8%E7%9A%84%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BB%A3%E7%A0%81%E6%9B%B4%E6%94%B9)

步骤 5：进行您的第一次代码更改
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

现在让我们让 Claude Code 进行一些实际的编码。尝试一个简单的任务：

复制

询问AI

```
> add a hello world function to the main file
```

Claude Code 将：
1.   找到适当的文件
2.   向您显示建议的更改
3.   请求您的批准
4.   进行编辑

Claude Code 在修改文件前总是请求许可。您可以批准单个更改或为会话启用”全部接受”模式。

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-6%EF%BC%9A%E5%9C%A8-claude-code-%E4%B8%AD%E4%BD%BF%E7%94%A8-git)

询问AI

询问AI


步骤 7：修复错误或添加功能
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Claude 擅长调试和功能实现。用自然语言描述您想要的内容：

复制

询问AI

```
> add input validation to the user registration form
```

或修复现有问题：

复制

询问AI

```
> there's a bug where users can submit empty forms - fix it
```

Claude Code 将：
*   定位相关代码
*   理解上下文
*   实现解决方案
*   如果可用，运行测试

[​](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-8%EF%BC%9A%E5%B0%9D%E8%AF%95%E5%85%B6%E4%BB%96%E5%B8%B8%E8%A7%81%E5%B7%A5%E4%BD%9C%E6%B5%81)

[​](https://code.claude.com/docs/zh-CN/quickstart#%E5%9F%BA%E6%9C%AC%E5%91%BD%E4%BB%A4)

基本命令
---------------------------------------------------------------------------------------------

以下是日常使用中最重要的命令：

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `claude` | 启动交互模式 | `claude` |
| `claude "task"` | 运行一次性任务 | `claude "fix the build error"` |
| `claude -p "query"` | 运行一次性查询，然后退出 | `claude -p "explain this function"` |
| `claude -c` | 继续最近的对话 | `claude -c` |
| `claude -r` | 恢复之前的对话 | `claude -r` |
| `claude commit` | 创建 Git 提交 | `claude commit` |
| `/clear` | 清除对话历史 | `> /clear` |
| `/help` | 显示可用命令 | `> /help` |
| `exit` 或 Ctrl+C | 退出 Claude Code | `> exit` |

查看 [CLI 参考](https://code.claude.com/docs/zh-CN/cli-reference) 获取完整的命令列表。
[​](https://code.claude.com/docs/zh-CN/quickstart#%E5%88%9D%E5%AD%A6%E8%80%85%E7%9A%84%E4%B8%93%E4%B8%9A%E6%8F%90%E7%A4%BA)

初学者的专业提示
-------------------------------------------------------------------------------------------------------------------------------------

对您的请求要具体

而不是：“fix the bug”尝试：“fix the login bug where users see a blank screen after entering wrong credentials”

使用分步说明

将复杂任务分解为步骤：

复制

询问AI

```
> 1. create a new database table for user profiles
```

复制

询问AI

```
> 2. create an API endpoint to get and update user profiles
```

复制

询问AI

```
> 3. build a webpage that allows users to see and edit their information
```

让 Claude 先探索

在进行更改之前，让 Claude 理解您的代码：

复制

询问AI

```
> analyze the database schema
```

复制

询问AI

```
> build a dashboard showing products that are most frequently returned by our UK customers
```

使用快捷方式节省时间

*   按 `?` 查看所有可用的键盘快捷方式
*   使用 Tab 进行命令补全
*   按 ↑ 查看命令历史
*   输入 `/` 查看所有斜杠命令
