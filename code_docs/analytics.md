分析
==

复制页面

查看您组织的 Claude Code 部署的详细使用情况洞察和生产力指标。

复制页面

Claude Code 提供了一个分析仪表板，帮助组织了解开发者使用模式、跟踪生产力指标，并优化他们的 Claude Code 采用。

分析目前仅适用于通过 Claude Console 使用 Claude API 的 Claude Code 的组织。

[​](https://code.claude.com/docs/zh-CN/analytics#%E8%AE%BF%E9%97%AE%E5%88%86%E6%9E%90)

访问分析
--------------------------------------------------------------------------------------------

导航到分析仪表板，地址为 [console.anthropic.com/claude-code](https://console.anthropic.com/claude-code)。
### [​](https://code.claude.com/docs/zh-CN/analytics#%E6%89%80%E9%9C%80%E8%A7%92%E8%89%B2)

所需角色

*   **主要所有者**
*   **所有者**
*   **账单**
*   **管理员**
*   **开发者**

具有**用户**、**Claude Code 用户**或**成员管理员**角色的用户无法访问分析。

[​](https://code.claude.com/docs/zh-CN/analytics#%E5%8F%AF%E7%94%A8%E6%8C%87%E6%A0%87)

可用指标
--------------------------------------------------------------------------------------------

### [​](https://code.claude.com/docs/zh-CN/analytics#%E6%8E%A5%E5%8F%97%E7%9A%84%E4%BB%A3%E7%A0%81%E8%A1%8C%E6%95%B0)

接受的代码行数

Claude Code 编写的代码行总数，用户已在其会话中接受。
*   排除被拒绝的代码建议
*   不跟踪后续删除

### [​](https://code.claude.com/docs/zh-CN/analytics#%E5%BB%BA%E8%AE%AE%E6%8E%A5%E5%8F%97%E7%8E%87)

建议接受率

用户接受代码编辑工具使用的次数百分比，包括：
*   Edit
*   Write
*   NotebookEdit

### [​](https://code.claude.com/docs/zh-CN/analytics#%E6%B4%BB%E5%8A%A8)

活动

**users**：给定日期的活跃用户数（左 Y 轴上的数字）**sessions**：给定日期的活跃会话数（右 Y 轴上的数字）
### [​](https://code.claude.com/docs/zh-CN/analytics#%E6%94%AF%E5%87%BA)

支出

**users**：给定日期的活跃用户数（左 Y 轴上的数字）**spend**：给定日期的总支出（美元）（右 Y 轴上的数字）
### [​](https://code.claude.com/docs/zh-CN/analytics#%E5%9B%A2%E9%98%9F%E6%B4%9E%E5%AF%9F)

团队洞察

**Members**：所有已向 Claude Code 进行身份验证的用户
*   API 密钥用户按 **API 密钥标识符**显示
*   OAuth 用户按**电子邮件地址**显示

**本月支出：** 当前月份的每用户总支出。**本月代码行数：** 当前月份的每用户接受代码行总数。
[​](https://code.claude.com/docs/zh-CN/analytics#%E6%9C%89%E6%95%88%E4%BD%BF%E7%94%A8%E5%88%86%E6%9E%90)
